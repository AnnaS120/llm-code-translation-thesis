# LM Code Translation: Python to Java  
====================================

Author: Anna Sosnowska  
Project Title: Exploring Prompt Engineering Strategies to Enhance the Capabilities of LLMs in Translating Code  
Supervisor: Jie Zhang at King's College London

Overview
--------
This project investigates how different prompts variations, model type, and temperature affect the robustness of large langauge models (LLMs) in Python-to-Java translations. The models compared were GPT-3.5-turbo and GPT-4o-mini and resulted in 9,000 translated snippets. Both automated and manual testing were used to evaluate the results.

Dataset Source: IBM's project CodeNet

Project Structure
-----------------
`python_dataset_original/`: Python dataset before processing.
`python_dataset_ready/`: Cleaned Python snippets ready for translation.
`pattern_variations/`: Python code variants generated using different code patterns (P1–P5).
`translated_java/`: Original Java code generated by LLMs.
`translated_java_cleaned/`: Cleaned and compilable Java code ready for runtime evaluation.
`evaluation/`:
  - `python_outputs.csv`: Python outputs.
  - `java_outputs.csv`: Outputs of Java code.
  - `detailed_results.csv`: Detailed coompilation, runtime, and output correctness results.
  - `rates_calculation.csv`: Aggregated performance statistics.

Scripts
-----------
`translator.py`: Translates Python snippets into Java by sending prompt variants to OpenAI models.
`code_pattern_generator.py`: Applies five structural prompt variations (P1–P5) to the Python dataset.
`replace_input.py`: Replaces original functions with modified inputs for testing.
`java_cleaner.py`: Cleans translated Java code and prepares it for execution.
`java_runner.py`: Compiles and runs Java code, as well as saves the outputs.
`python_runner.py`: Runs Python code and saves the outputs.
`rates_calculator.py`: Calculates and saves compilation, runtime, and output correctness metrics.
`resultsanalyser.py`: Performs statistical analysis and creates performance summaries.

Models and Parameters
---------------------
Models: gpt-3.5-turbo, gpt-4o-mini
Temperatures: 0.0, 0.5, 0.8
Prompt types: Natural language (N1–N5), Pattern-based (P1–P5)

Running the Evaluation
----------------------
1. Prepare the Python dataset by running `replace_input.py`.
2. Generate prompt variations using `code_pattern_generator.py`.
3. Run the translator (`translator.py`).
4. Clean Java outputs with `java_cleaner.py`.
5. Run and evaluate both Python and Java snippets using `python_runner.py` and `java_runner.py`
6. Analyse results with `resultsanalyser.py`.
7. Calculate rates by running `rates_calculator.py`.


Key Findings
------------
- GPT-3.5-turbo achieved higher correctness (87.44%) and runtime stability (97.35%) than GPT-4o-mini.
- Lower temperature (0.0) produced more accurate and stable outputs.
- Different prompt phrasings impacted the robustness of code translation. Directive prompts (like N4: “Preserve original behaviour”) performed best.
- Pattern variations with deeper logic changes (P3) reduced accuracy more than superficial syntax edits (P5).
